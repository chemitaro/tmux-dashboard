# 列優先（縦方向優先）配置への変更

## 変更内容

ダッシュボードのタイル配置順序を**行優先（横方向）**から**列優先（縦方向）**に変更しました。

### 変更前（行優先）
```
+---+---+---+
| A | B | C |  ← 左から右へ
+---+---+---+
| D | E |   |  ← 次の行へ
+---+---+---+
```

### 変更後（列優先）
```
+---+---+---+
| A | C | E |  ← 各列の上から下へ
+---+---+---+
| B | D |   |  ← 次の列へ
+---+---+---+
```

## 実装の詳細

### 1. layout.py の変更
- `tile_positions()` 関数のループ順序を変更
- 外側ループ：列（columns）
- 内側ループ：行（rows）

### 2. orchestrator.py の変更
- pane のソートキーを `(x[2], x[1])` から `(x[1], x[2])` に変更
- x[1]=left（X座標）、x[2]=top（Y座標）
- 2箇所で同様の変更（apply_titles と run_once）

### 3. テストの更新
- 新規テストファイル `test_column_major_ordering.py` を追加
- 既存の `test_layout.py` のテストケースを列優先に更新

## 利点

1. **セッションの縦並び**: セッション名が縦方向に順序良く並ぶ
2. **視覚的な流れ**: 上から下への自然な読み取り順序
3. **グループ化**: 関連するセッションを同じ列に配置しやすい

## テスト結果

全54件のテストが成功:
- 列優先配置の新規テスト: 4件
- 既存テストへの影響: なし
- 総合テスト結果: 54 passed, 3 xfailed

## 使用方法

設定変更は不要です。ダッシュボードは自動的に列優先配置でセッションを表示します。
